# FileZilla

FileZilla er et program som lar deg overføre filer mellom pc-en din og sputifu.

> [!WARNING]  
> **OBS: VÆR FORSIKTIG!!!**  
> Her har du makten til å slette og føkke med hele samlingen vår. Vær varsom!

- Installer: [https://filezilla-project.org/download.php](https://filezilla-project.org/download.php)

## Oppsett

- Host: sftp://files.sputifu.no
- Username: Sendes på signal
- Password: Sendes på signal
- Port: 23

Du trenger bare å putte denne informasjonen inn første gangen. Alle andre ganger kan du koble deg til med **«Quickconnect»**

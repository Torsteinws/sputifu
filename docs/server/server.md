# Generelt

- OS: Ubuntu server 26.04
- Musikkfiler er lagret på en ekstern storage box.
    - Storage box-en mountes `/mnt/ftp` når serveren starter opp.

## Hardware

- Arkitektur: arm
- Ram: 4GB
- Disk: 40GB
- Ftp-disk: 1TB
